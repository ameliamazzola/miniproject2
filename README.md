# MiniProject2 — Traffic Vehicle Recognition

## Objective
Use the UA-DETRAC dataset to:

- Detect vehicles in traffic videos
- Compute:
  - Maximum road load (vehicles in a single frame)
  - Traffic flow over time (vehicles passing through)
